A universe that creates its own events

Events are born one at a time. Each newborn picks some existing events as its direct causes and inherits their whole past. Nothing else exists: no space, no clock. Height is cosmic time, the longest chain of causes back to the first event. The width of each row is how many events share that cosmic time.

Vertical position is cosmic time, computed from the order alone. Horizontal position is only a drawing choice; the number of events in a row is what is real.
