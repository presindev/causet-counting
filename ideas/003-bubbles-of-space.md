# 003 — Bubbles of space (filled = matter, empty = void)

## The intuition (Roberto, end of session 1)
Space is made of discrete "bubbles". Each bubble is either filled (matter) or empty (void). Creating space = a new
bubble appearing between two existing ones, so light has to travel a longer path (expansion, redshift?).
Destroying space = a bubble bursting, e.g. at the centre of a black hole.

## First reactions (to discuss next session)
- This is a *spatial* picture (bubbles at a given cosmic time), whereas idea 001/002 use *spacetime events*.
  With a cosmological frame (C5) a spatial slice is meaningful: bubbles ≈ events in one cosmic-time layer?
- Bubble occupancy (filled/empty) gives a natural place for the **missing matter** in C1–C8.
- Creation between two bubbles lengthening light paths = cosmological expansion; check whether it gives redshift.
- Literature neighbours: GFT condensates (occupation numbers of quanta of space), quantum graphity (link
  on/off), causal-set growth. `[literature]`
- Tension to examine: "a bubble bursting" in a relational model — what replaces it? (Events can't un-happen;
  layer size can shrink.)

## Translation into the event picture (session 2)
- Bubble at cosmic time h = event in layer h; a bubble *persisting* = a chain of events (its worldline).
- Two bubbles touch = spatial neighbours in a layer; relational definition needed, e.g. siblings sharing a recent
  common cause, or causal-set spacelike distance (Rideout–Wallden 2009, arXiv 0810.1768).
- Creating a bubble between two = a new chain branching in between ⇒ more hops for light ⇒ expansion (test: count
  hops between two fixed comoving chains as layers grow).
- Filled/empty = a field living on events (matter on causal sets: scalar fields, Sorkin–Johnston). Supplies matter.
- Bursting bubble (BH centre): relationally, layers shrinking inside a trapped region. Related: Dou–Sorkin 2003,
  BH entropy ∝ number of causal links crossing the horizon ∝ area. `[literature]`

## Semi-full bubbles = wavefunction (Roberto, session 2)
- `[established]` As *amplitude per bubble*: exactly lattice quantum mechanics. ψ assigns a complex number to each
  bubble; |ψ|² = probability of finding the particle there. On causal sets: quantum fields on events
  (Sorkin–Johnston, `[literature]`).
- Caveat: "partly filled with matter" taken literally is Schrödinger's original charge-density reading, which failed:
  (i) detection is all-or-nothing (one whole click); (ii) N particles need a wavefunction on N-tuples of bubbles
  (configuration space), so entangled pairs cannot be drawn as fillings of single bubbles. Keep "fill" = amplitude.
- In QFT language: occupation number per bubble (Fock space), superposed. Close to GFT.
